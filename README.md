# Grabador de reuniones

Para instalarlo: **[Bajar el instalador](https://github.com/gersoncoder15/grabador-reuniones-descargas/releases/latest/download/Instalar-GrabadorReuniones.exe)** → doble clic → Siguiente.

- Si Windows dice «Windows protegió su PC»: «Más información» → «Ejecutar de todas formas».
- Al abrirla, elegí la versión (de prueba o ilimitada) y pedí el código: te lo da el desarrollador.
  Sin ese código la app no se puede usar.
- Tus reuniones quedan sólo en tu PC.
